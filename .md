# Forge Prompt — ColdStack Railgun Tab: Fix Swallowed Error Notifications (Closure Bug)

> **Project:** ColdStack (`/mnt/b/Blockchain/coldstack/`)
> **Task:** Four deferred-error lambdas in `src/railgun_tab.py` reference the exception variable `e` after its `except` scope has ended — Python deletes `e` at scope exit, so every one of these callbacks crashes with `NameError: cannot access free variable 'e'` and the user sees NOTHING when a Railgun step fails.
> **Type:** IMPLEMENTATION ONLY — no commit, no build, no VERSION, no docs. Rides the v5.3.2 line.
> **Evidence (live, 2026-08-31 15:45):** user clicked Start Sidecar with no sidecar dir present; `gui_debug.log` shows `railgun_tab.py line 329 in <lambda> → NameError` — the FileNotFoundError message was never displayed. User experience: silent failure, greyed buttons, no clue why.

## The four broken lines

All in `src/railgun_tab.py`, all the same pattern:

- **Line 329** — `self.gui.root.after(0, lambda: self.gui.show_notification(f"Sidecar error: {e}", error=True))`
- **Line 396** — `... lambda: ... f"Engine init failed: {e}" ...`
- **Line 457** — `... lambda: ... f"Wallet load failed: {e}" ...`
- **Line 510** — `... lambda: ... f"Balance status failed: {e}" ...`

## Fix pattern (apply to all four)

Capture the message into a plain local BEFORE scheduling the callback:

```python
except Exception as e:
    msg = f"Sidecar error: {e}"
    self.gui.root.after(0, lambda: self.gui.show_notification(msg, error=True))
```

(For each site use its own wording; `msg` is a normal closure variable that survives scope exit. Do NOT use `lambda e=e:` default-arg style — capture-into-local is clearer and consistent.)

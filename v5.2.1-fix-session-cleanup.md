## The Problem

When the user closes ColdStack via the window X button or Alt+F4, the `.key_manager_session` file is NOT deleted. This file contains the base64-encoded master password, which is trivially decodable by anyone with filesystem access.

The file is created by `create_session()` in `main.py` (called on successful login at line 535 of `gui_main_v5.py`). It's supposed to be deleted by `end_session()` (called from `lock_session()`). But `lock_session()` is only triggered by:
1. The "Lock" button in the status bar
2. The 5-minute auto-lock timer

There is NO handler for the `WM_DELETE_WINDOW` event (window close). When the user closes the window, Tkinter destroys the root and exits `mainloop()` without calling `lock_session()` or `end_session()`.

## The Fix

### File: `src/gui_main_v5.py`

**Change A: Add `WM_DELETE_WINDOW` protocol handler in `__init__`**

In the `__init__` method, after `self.root = ctk.CTk()` and before `self.create_login_screen()`, add:

```python
        # v5.2.1: Handle window close event — clean up session file
        self.root.protocol("WM_DELETE_WINDOW", self._on_close)
```

Find the section where `self.root` is created (around line 307):

```python
        self.root = ctk.CTk()
        self.root.title("ColdStack - Secure Crypto Key Vault")
        self.root.geometry("1200x800")
```

Add after the geometry line:

```python
        # v5.2.1: Handle window close event — clean up session file
        self.root.protocol("WM_DELETE_WINDOW", self._on_close)
```

**Change B: Add `_on_close()` method**

Add this method to the `ColdStackGUI` class. Place it right before the `lock_session` method (around line 2331):

```python
    def _on_close(self):
        """Handle window close event — ensure session file is cleaned up.

        This fires when the user closes the window via X button, Alt+F4,
        or any OS-level window close action. Without this, the
        .key_manager_session file (containing the base64-encoded password)
        would persist on disk.
        """
        try:
            # Stop the embedded agent server first (frees the port)
            self._stop_embedded_agent()
        except Exception:
            pass

        try:
            # Delete the session file if it exists
            if self.key_manager:
                self.key_manager.end_session()
        except Exception:
            pass

        # Destroy the root window and exit
        try:
            self.root.destroy()
        except Exception:
            pass
```

**Change C: Add `atexit` fallback handler**

As a belt-and-suspenders safety net (in case `WM_DELETE_WINDOW` doesn't fire, e.g., process kill from Task Manager), register an `atexit` handler. At the top of the file, near the existing imports, add:

```python
import atexit
```

Then in `main()` at the bottom of the file, add the atexit registration:

Find:

```python
def main():
    """Main entry point for ColdStack GUI application."""
    app = ColdStackGUI()
    app.run()
```

Replace with:

```python
def main():
    """Main entry point for ColdStack GUI application."""
    app = ColdStackGUI()

    # v5.2.1: atexit fallback — delete session file if WM_DELETE_WINDOW didn't fire
    def _cleanup_session():
        try:
            if app.key_manager:
                app.key_manager.end_session()
        except Exception:
            pass
    atexit.register(_cleanup_session)

    app.run()
```

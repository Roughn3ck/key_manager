## Context

The Krystal adapter (`src/venue_adapters/krystal_adapter.py`) registers successfully with `VENUE_KEY = "krystal"`. The LP tab builds its platform dropdown from `lp_engine.list_venues()` and maps raw keys to friendly names via `LP_PLATFORM_MAP_reverse`.

Currently `LP_PLATFORM_MAP` only has Hyperliquid:

```python
LP_PLATFORM_MAP = {
    "HyperEVM (Project X)": "hyperliquid",
}
```

So when Krystal is discovered, it appears as the raw string "krystal" in the dropdown instead of a friendly name.

## Task

### Modify `src/gui_main_v5.py` (ONE change — ~1 line)

Find the `LP_PLATFORM_MAP` dictionary (around line 297-300):

```python
LP_PLATFORM_MAP = {
    "HyperEVM (Project X)": "hyperliquid",
}
```

Replace with:

```python
LP_PLATFORM_MAP = {
    "HyperEVM (Project X)": "hyperliquid",
    "Krystal (BSC)": "krystal",
}
```

That's it. The `LP_PLATFORM_MAP_reverse` is already built dynamically on the next line:

```python
LP_PLATFORM_MAP_reverse = {v: k for k, v in LP_PLATFORM_MAP.items()}
```

So it will automatically include `"krystal" -> "Krystal (BSC)"`.

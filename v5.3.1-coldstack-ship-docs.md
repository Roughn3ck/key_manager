## Context

The Orca Token-2022 close fix was implemented on Aug 30 (after the v5.3.0 commit) and lives **uncommitted** in the working tree: `src/venue_adapters/orca_writer.py` (+11/−1). Root cause: positions opened via Orca's current UI mint **Token-2022 position NFTs** (metadata extension); the legacy `closePosition` instruction types `position_mint` as SPL-only and fails with `AccountOwnedByWrongProgram` (3007). The fix selects the dedicated `closePositionWithTokenExtensions` instruction (discriminator `01b6873b9b1963df`) when the position NFT belongs to Token-2022.
